# 🏗️ MN Builders

A modern and responsive construction company website developed using React and Vite. The platform showcases residential and commercial construction projects, company services, project galleries, and customer contact facilities.

## 🌟 Overview

MN Builders is a construction and real estate company dedicated to delivering high-quality residential and commercial projects. This website serves as a digital portfolio where potential clients can explore completed projects, learn about services, and contact the company for their construction requirements.

## ✨ Features

- Modern responsive user interface
- Interactive landing page with hero section
- About Us section with company information
- Residential construction showcase
- Commercial construction showcase
- Project gallery
- Contact form for customer inquiries
- Navigation menu for easy browsing
- Mobile-friendly design

## 🚀 Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd mn-builders
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```bash
http://localhost:5173
```
